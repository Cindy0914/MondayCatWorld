## MondayCat World🐱
> 2D 플랫폼 게임  
> 스파르타 메타버스 만들기 과제 2025.02.16 ~ 2025.02.20  
> 자유롭게 맵을 돌아다니고 미니게임을 즐길 수 있음

## 🎮 조작법
| 키 입력    | 동작     |
|---------|--------|
| `W` `↑` | 위로 이동  |
| `A` `←` | 왼쪽 이동  |
| `S` `→` | 아래로 이동 |
| `D` `→` | 오른쪽 이동 |
| `Space` | 대화 넘기기 |
| `E`     | 상호작용   |


## 기능 소개  
### 😊 프로필
![프로필](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdn%2Fb2mYDq%2FbtsMpUeCvUg%2FJaGcTYgrY6AYTEwAm1tib0%2Fimg.png)  
화면 하단 좌측에 있는 프로필 버튼을 클릭하면 프로필 창이 나타납니다.  
프로필 창에서 원하는 캐릭터로 변경할 수 있습니다.

### 🐕 펫
![펫](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdn%2FbaU6Eu%2FbtsMqlwfTOB%2FSsdccC554X0cC5hSOFGdo0%2Fimg.png)  
마을 안에 있는 펫 상인에게서 펫을 구매할 수 있습니다.  
펫 구매는 미니게임에서 획득한 포인트로 구매할 수 있습니다.  
펫을 구매하면 펫이 캐릭터와 함께 동행하며, 펫을 변경할 수도 있습니다.

### 🕹️ 미니게임
![미니게임](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=https%3A%2F%2Fblog.kakaocdn.net%2Fdn%2Fw9vhp%2FbtsMoXpF4qP%2FlGr42aui5m7HpRXH4dbQ00%2Fimg.png)  
오른쪽 위의 숲으로 들어가면 미니게임 오브젝트가 있습니다.  
상호작용 하여 미니게임을 시작할 수 있습니다.  
미니게임을 클리어하고 포인트를 획득할 수 있습니다.
